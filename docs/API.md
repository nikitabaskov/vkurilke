# HTTP API

Все ответы — JSON. Времена — Unix seconds UTC.

## Авторизация

`POST /api/auth` с телом `{ "init_data": "..." }` возвращает `{ "token": "..." }`. Остальные приватные запросы передают заголовок `Authorization: Bearer <token>`.

`initData` проверяется по HMAC-SHA256 и возрасту — не старше часа, допустимое опережение часов 30 секунд ([Telegram Mini Apps](https://core.telegram.org/bots/webapps#validating-data-received-via-the-mini-app)). Токен сессии случайный, живет 24 часа; в БД хранится только его SHA-256. Пользовательские ID в запросах смены статуса не принимаются — сервер берет их из сессии.

## Эндпоинты

| Метод и путь | Назначение / тело |
| --- | --- |
| `GET /healthz` | HTTP и соединение с БД; без авторизации |
| `GET /api/meta` | Публичное имя бота и интервалы |
| `GET /api/me` | Пользователь, настройки, право создавать комнаты |
| `GET /api/me/statistics?period=today` | Личная статистика по всем комнатам |
| `GET /api/groups/{id}/statistics?period=today` | Итоги комнаты и статистика текущих участников, только для участников комнаты |
| `GET /api/groups` | Доступные комнаты и роли; инвайт виден только управляющим |
| `POST /api/groups` | Создать комнату: `{ "name": "Общага" }` |
| `POST /api/groups/join` | Вступить: `{ "code": "..." }` |
| `POST /api/groups/{id}/invite` | Заменить приглашение |
| `POST /api/groups/{id}/members` | `{ "user_id": 123, "action": "add\|remove\|admin\|member" }` |
| `DELETE /api/groups/{id}/membership` | Выйти из комнаты; владелец выйти не может |
| `GET /api/status?group_id=...` | Список участников, собственный активный статус, серверное время |
| `POST /api/status/change` | `{ "group_id": "...", "status": "going\|smoking\|idle", "duration_minutes": 5 }` |
| `POST /api/status/confirm` | `{ "token": "...", "here": true }` |
| `PUT /api/settings/notifications` | Все три поля: `{ "session": true, "arrival": true, "departure": false }`. `arrival` и `departure` сохраняются, но не используются: приходы и уходы видны в карточке сеанса |
| `POST /api/settings/toggle-notifications` | Переключить социальные уведомления |

`going` принимает длительности 3, 5 или 10 минут; кнопка бота всегда выбирает 5. Mini App корректирует часы по `server_time`. Данные комнаты доступны только ее участникам; чтение списка не меняет активную комнату пользователя.

## Статистика

Обязательный `period`: `today` (с 06:00 по Новосибирску), `week` (последние 7×24 часа), `month` (последние 30×24 часа), `all` (вся сохраненная история). Другие значения дают 400. До 06:00 начало `today` — вчера в 06:00.

Ответ содержит `period`, `from`, `server_time`, `timezone` (`Asia/Novosibirsk`), `totals: { outings, seconds }`, `sessions`, `session_seconds`, `leaderboard: [{ user_id, name, outings, seconds }]`. В личном ответе `sessions` и `session_seconds` равны 0, `leaderboard` — пустой массив. В комнате это количество общих сеансов, их суммарная длительность и текущие участники, включая нулевые итоги.

`outings` считает начала посещений в `smoking` внутри периода, `seconds` — только часть времени внутри периода, включая незавершенные посещения до `server_time`. Повторный приход считается отдельно; `going` не учитывается. Число сеансов также считается по их началу, длительность — по пересечению с периодом. Поэтому нулевое число выходов или сеансов может сопровождаться ненулевым временем. `totals.seconds` комнаты — сумма времени людей, `session_seconds` — длительность общих сеансов без умножения на число участников. В итогах остаются выходы ушедших участников; лидерборд включает только текущий состав и сортируется по выходам, времени, ID.

Оценки доступны через callback-кнопки Telegram `like:<session_id>` / `dislike:<session_id>` в завершенной карточке. Сервер проверяет членство и участие в этом сеансе; одна оценка на человека с возможностью замены. Повтор одинакового голоса не создает новую запись или рассылку.

## Коды ошибок

| Код | Когда |
| --- | --- |
| 400 | Некорректное тело или параметры |
| 401 | Нет токена, токен истек или `initData` не прошел проверку |
| 403 | Нет доступа к комнате или действию |
| 404 | Комната, приглашение или пользователь не найдены |
| 409 | Бот не запущен пользователем, либо сеанс/запрос уже завершен |
| 429 | Превышен лимит запросов авторизации |

Тело ошибки: `{ "error": "текст для пользователя" }`.
